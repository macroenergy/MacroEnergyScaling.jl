MacroEnergyScaling.scale_and_update_constraint! — Method
scale_and_update_constraint!(con_ref::ConstraintRef, con_obj, rhs::Real, scaling_settings::ScalingSettings)

Scale the coefficients and RHS of the constraint con_ref using the scaling settings scaling_settings without changing its ConstraintRef.

First we check if we can scale the right-hand side constant without creating proxy variables. Next, we iterate over the variable-coefficient pairs and scale them using proxy variables if necessary. The scaled variable-coefficient pairs are then applied to the original constraint in place.
